# 📔 Дневник — Личные заметки

Простое и красивое веб-приложение для ведения дневника и личных записей.

![Дневник](https://img.shields.io/badge/React-18-blue) ![TypeScript](https://img.shields.io/badge/TypeScript-5-blue) ![Tailwind](https://img.shields.io/badge/Tailwind-4-blue)

## ✨ Возможности

- 📝 **Богатый редактор** — жирный, курсив, заголовки, списки, чек-листы, цитаты, изображения
- 🏷️ **Теги** — 5 цветов для организации заметок
- 🔍 **Поиск** — мгновенный поиск по заголовкам и содержимому
- 📌 **Закрепление** — важные заметки всегда сверху
- 💾 **Автосохранение** — все данные сохраняются автоматически
- 📱 **Адаптивность** — работает на десктопе, планшете и мобильных
- ⌨️ **Горячие клавиши** — `Ctrl+N` (новая), `Ctrl+B/I/U` (форматирование)
- 🌐 **Офлайн-режим** — работает без интернета после первой загрузки
- 📲 **Установка** — можно установить как приложение на компьютер

## 🚀 Установка на компьютер

### Способ 1: Как веб-приложение (PWA) — РЕКОМЕНДУЕТСЯ

Самый простой способ — установить как PWA через браузер:

1. **Откройте приложение** в браузере Chrome, Edge или Яндекс.Браузер
2. **Найдите иконку установки** в адресной строке (обычно справа)
   - Chrome: иконка "Установить приложение" ⬇️
   - Edge: иконка "Установить это приложение" 📥
3. **Нажмите "Установить"**
4. Готово! Приложение появится в меню Пуск и будет работать как обычная программа

**Альтернативный путь через меню:**
- Chrome: `⋮` → "Установить приложение" / "Добавить на главный экран"
- Edge: `⋯` → "Приложения" → "Установить это приложение"

После установки приложение:
- Запускается без адресной строки браузера
- Работает офлайн
- Хранит данные локально на вашем устройстве
- Обновляется автоматически

### Способ 2: Запуск из исходного кода (для разработчиков)

#### Требования
- [Node.js](https://nodejs.org/) версии 18 или выше
- npm (устанавливается вместе с Node.js)

#### Шаги установки

```bash
# 1. Клонируйте репозиторий или скачайте файлы
git clone <url-репозитория>
cd diary-app

# 2. Установите зависимости
npm install

# 3. Запустите в режиме разработки
npm run dev
```

Откройте в браузере: **http://localhost:5173**

#### Сборка production-версии

```bash
# Собрать оптимизированную версию
npm run build

# Запустить локальный сервер для проверки
npm run preview
```

Собранные файлы появятся в папке `dist/` — их можно разместить на любом веб-хостинге.

---

### Способ 3: Размещение на хостинге

Приложение полностью статическое — после сборки (`npm run build`) все файлы в папке `dist/` можно загрузить на любой хостинг:

- **GitHub Pages** — бесплатно
- **Vercel** — автоматически из Git
- **Netlify** — drag & drop папки `dist/`
- **Любой веб-сервер** (Apache, Nginx)

## 🔒 Приватность

Все данные хранятся **исключительно локально** в вашем браузере (LocalStorage). Никакая информация не отправляется на сервер. Вы полностью контролируете свои записи.
